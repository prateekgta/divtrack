System Overview
All-Java backend. Browser talks to the Spring Cloud Gateway which proxies to 3 independent Spring Boot microservices. Each service owns its own PostgreSQL database — no shared tables, no cross-DB joins. Redis is the shared bus for caching and WebSocket fan-out.
① Spring Cloud Gateway (:3000) — single entry point. Validates JWT, routes requests, enforces rate limits. Also handles WebSocket upgrade.
② Auth Service (:8081) — RSA key pair holder. Signs JWTs (private key). All other services only verify (public key).
③ Portfolio Service (:8082) — Holdings CRUD, alerts. Reads Redis for live prices instead of calling Market service directly.
④ Market Data Service (:8083) — Scrapes Yahoo Finance every 60s via Jsoup. Circuit breaker (Resilience4j) protects against failures.
⑤ Redis — Cache (TTL 90s per ticker), Pub/Sub channel prices:live, rate limiting counters. Shared across all pods.

Login Flow
User sends credentials → only auth-service ever touches the private key → short-lived JWT returned in body + refresh token in httpOnly cookie.
1Browser: POST /v1/auth/login {email, password}
2Gateway: public route — no JWT check needed. Proxies straight through.
3Auth Service: loads user from auth_db. Verifies BCrypt hash (cost=12).
4Auth Service: signs JWT using RSA private key (only this service has it). Saves refresh token hash to DB.
5Response: accessToken (15 min) in JSON body + refreshToken in httpOnly cookie.
6Browser stores accessToken in JS memory only — never localStorage (XSS protection).
Add Holding Flow
User adds a stock to their portfolio. Gateway validates JWT locally (no network call) then Portfolio service reads cached price from Redis to compute monthly income.
1Browser: POST /v1/portfolio/holdings {ticker: "STRC", amount: 150000} with JWT header.
2Gateway: verifies RS256 JWT using public key only — no auth-service call needed.
3Portfolio Service: saves holding to portfolio_db. Note: user_id is stored as plain VARCHAR — no FK to auth DB.
4Portfolio Service: reads stock:price:STRC from Redis cache (TTL=90s). No HTTP call to market service.
5Computes: monthly = amount × yield / 12. Returns {holdingId, ticker, monthlyIncome: 1437.50}.
Live Prices (WebSocket)
Background job scrapes Yahoo Finance every 60s, caches in Redis, publishes to Pub/Sub channel. Gateway fans out to all connected WebSocket clients.
1@Scheduled PriceUpdateJob fires every 60s in Market Data Service.
2YahooFinanceScraper.scrape("STRC") — Jsoup fetches HTML from finance.yahoo.com/quote/STRC.
3Resilience4j CircuitBreaker wraps call — opens after 3 failures, retries after 30s.
4PricePublisher writes to Redis: stock:price:STRC → {yield, price} (TTL=90s) then publishes to channel prices:live.
5Gateway is subscribed to prices:live via ReactiveRedisMessageListenerContainer.
6Gateway fans out {type:"PRICE_UPDATE", ticker:"STRC", yield:11.5, price:99.8} to all WS clients watching STRC.
7LivePriceBadge.tsx re-renders with new yield. No page refresh needed.
